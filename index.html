The limit isn't yours. It belongs to the model.

Every other API hands you a personal quota to burn through. OpenFlow gives each model one bucket and everyone drinks from it. Your key says who you are — it doesn't buy you a private allowance. Free, no tiers, no card.

Three steps to your first call

  1. Make an account

    Email and password. Signing up mints your owner ID, which every key you create belongs to.

  2. Generate a key

    Shown once. Copy it then — only its fingerprint is stored, so it can't be shown again.

  3. Point your client here

    Anything that speaks the OpenAI chat format works. Change the base URL and the key, leave everything else.

It looks like every other chat API

Because it is one. The only thing that changes is the base URL:

…

# curl
curl …/v1/chat/completions \
  -H "Authorization: Bearer of_live_your_key" \
  -H "Content-Type: application/json" \
  -d '{"model":"mistral-small-latest","messages":[{"role":"user","content":"hi"}]}'

# python — no SDK needed
import requests
r = requests.post(
    "…/v1/chat/completions",
    headers={"Authorization": "Bearer of_live_your_key"},
    json={"model": "openai/gpt-oss-20b",
          "messages": [{"role": "user", "content": "hi"}]},
)
print(r.json()["choices"][0]["message"]["content"])

# openai sdk — just repoint it
client = OpenAI(base_url="…/v1", api_key="of_live_your_key")

Streaming works — pass "stream": true and read the event stream as usual. GET /v1/models returns the current list with each limit attached.

What happens when a model is full

Your request waits a few seconds for a slot. If none opens you get a 429 naming the model, its limit, and the seconds until the next opening. That isn't a penalty aimed at you — someone else was mid-call. Switch to a model with room or wait it out. The gauges above tell you which is which before you send anything.
